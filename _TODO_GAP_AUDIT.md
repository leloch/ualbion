# What Is Still Missing for UAlbion to Play Albion (1996) Start-to-Seed-Ending, 100%, Bug-Free

> Compiled 2026-06-13 by a multi-agent audit (8 web ground-truth axes on the real game +
> 5 doc-extraction passes + 13 per-dimension code auditors + per-finding adversarial
> verification). 98 findings, 67 confirmed gaps, 31 overturned ledger claims. Severities
> reflect adversarial verification against the code, **not** the project's self-reported
> ledger. Every item cites `file:line`. Companion to `_TODO_1TO1.md` and `_TODO_100PCT.md`.

Repo: `F:\dev\albion\ualbion`.

## 1. Bottom line

**No — the game cannot be completed today, and the wall is the entire back half of the quest, not a single bug.** The intro is empirically reachable (one recorded run reaches the Hunter Clan, beat 5 of ~11), but four independent, fully-confirmed engine blockers each individually prevent a 100% start-to-Seed playthrough, and they compound:

1. **The canonical ending literally cannot fire.** The only win condition is the scripted surrender/Seed-deploy branch, and the `ask_surrender` opcode is a parse-only silent no-op with no handler. The AI is intentionally unkillable (~4500 LP, weapon-immune), so there is no fallback. (`AskSurrenderEvent.cs`, `Battle.cs`, `CombatManager.cs`)
2. **The economy is dead.** Buying from any merchant is a free pickup with no gold debit; selling raises an event with zero subscribers. The linear quest gates regions on gold (ship passage, hiring guide Ohl, trainers). (`InventoryManager.cs`, `InventorySellEvent.cs`)
3. **Tool-on-tile puzzles can't happen.** The `UseItem` world-verb is absent from both 2D and 3D selection menus, and there is no "use which item" picker — this is the verb behind pick-axe-on-cracked-wall, screwdriver-on-Toronto-lasers (gates the finale), and staff/water-on-force-fields. (`SelectionHandler2D/3D.cs`)
4. **Lever/pressure-plate wall openings silently fail in 3D dungeons.** `ChangeIconEvent` is unsubscribed in `DungeonMap`, so portcullis/wall-dissolve chains in Drinno, Kounos, Kenget Kamulos, and the Toronto never take effect — a physical hard-stop. (`DungeonMap.cs`)

Beyond these, **no chapter past the Hunter Clan has ever been run empirically**, and several confirmed gaps (`WordKnown` persistence for "Umajo Danu", `CreateTransport`, `QueryType` parse-throws) sit squarely on that unverified late path. The single most important corrective fact for the maintainer: **the ledger has drifted badly in both directions** — multiple "open" items are actually done (presentation/FLIC playback, all four trainers, AP/mastery growth, paid services, day/night gating), while several "done/deferred" items hide real bugs (the leave-side home-NPC off-by-one is a recruit-soft-lock blocker the tests document rather than catch).
